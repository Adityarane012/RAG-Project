# Conclusion and Future Scope

This project built and evaluated HF Model Finder, a constraint-verified RAG system over 15,991 Hugging Face models in eleven tasks. The results support four conclusions. (1) Verification in code removed constraint violations: none on 75 normal queries against 50.4% for naive RAG and 25.9% to 32.8% for the Hub's filters. (2) Honest unknowns beat guesses: 83.3% of recommendations were fully verified, the rest were marked, and the system never claimed verification when no model could pass. (3) Verifying wide and showing narrow matters (72.3% to 83.3% fully verified). (4) Verification did not cost relevance: in a study graded by language-model judges the system had the highest mean grade (1.28 of 2).

**Future scope.** (1) Validate the judged grades with human annotators on a sample. (2) Extend the evaluation queries to all eleven tasks, with queries from people other than the builder. (3) Reduce unknowns without guessing: parse GGUF and ONNX sizes separately, read custom licence text, extract translation direction from cards. (4) A stronger abstention policy and a re-ranker without a quota. (5) Keep the index fresh with an incremental pipeline and live lookup in check-a-model mode. (6) Add tasks that are currently refused or mapped to the nearest task, and run a user study comparing time to a usable model with the Hub's search.

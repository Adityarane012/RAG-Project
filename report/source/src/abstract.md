Choosing a pre-trained model on the Hugging Face Hub is a constrained-selection problem. A developer wants "a Marathi named-entity model under 500 MB that I can use commercially", and four of those five requirements are hard constraints (task, language, size and licence rights) that a model either meets or does not. Keyword search cannot read the soft part of such a request. The Hub's own filters match a licence *string* rather than a right. A plain retrieval-augmented generation (RAG) pipeline recommends whatever sounds relevant: in this work it broke at least one stated constraint on half of its recommendations.

This report presents **HF Model Finder**, a constraint-verified RAG system. A language model only parses the request into constraints and later writes a cited explanation; every pass, fail or unknown verdict is decided by deterministic code that reads model metadata, never model output or card text. Missing metadata is shown as an explicit *unknown* instead of being guessed or silently dropped. The system is a LangGraph pipeline with clarifying questions, an editable reading of the request and a prompt-injection defence. It searches 15,991 models across eleven tasks (speech, translation, text, vision, generation, summarization and question answering) with a deliberate emphasis on Indian languages, using hosted multilingual embeddings in Pinecone and a Streamlit interface.

The system was evaluated against naive RAG, BM25 with filters and the Hub's own filters on 100 queries written before any tuning. On 75 normal queries it recommended no model that fails a requested constraint (0.0% against 50.4% for naive RAG and 25.9% to 32.8% for the Hub filters) and 83.3% of its recommendations were fully verified (29.1% for naive RAG). It asked a clarifying question on all 15 vague queries and never claimed verification when no model in the corpus could pass. In a blind relevance study graded by independent language-model judges (not humans), it had the highest mean grade (1.28 of 2). The report states its limits plainly: 27% to 30% of models have unknown size, relevance and faithfulness were judged by language models, and the six added tasks were checked by smoke tests rather than the 100-query study.

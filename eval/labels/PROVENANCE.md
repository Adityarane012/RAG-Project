# Who produced these labels

**`labels_pass1.csv`, `labels_pass2.csv` and `faithfulness_labels.csv` were produced by independent Claude agents (LLM judges), not by
a human.** `labeller.txt` says so and the reports print it.

- **Relevance, pass 1:** 8 agents, each reading one blind batch (about 5 queries, 81 to 98 pairs): the request, the model id and the
  card excerpt, with no system names, no extractor fields and no key file. Each graded by reading, with the 0/1/2 rubric in
  `docs/evaluation-plan.md` §5. They were told not to write code or keyword rules, and not to read anything else.
- **Relevance, pass 2:** 3 other agents graded the same 15 queries (266 pairs) from scratch in a different order, without access to pass 1.
  The agreement between the two passes measures the consistency of LLM judging, not agreement with humans.
- **Faithfulness:** 2 agents counted the factual claims in each of 28 explanations and how many the shown card passages support.
- **Audit trail:** `llm_judge_reasons.csv` holds each agent's one-line reason for every grade. Timestamps in the label files are the real
  modification times of the judges' output files. `scripts/import_llm_judgements.py` validates and imports the files (every pair graded
  exactly once, grades in 0/1/2).

An earlier version of these files was generated by a keyword rule with a simulated pass 2; it was deleted (commit `6f13bf6`).

**Limits.** The judges are the same model family as the assistant that built the system, so shared blind spots are possible, and no human
has checked the grades. To add human evidence, copy `relevance_sheet.csv` to another folder, run
`LABEL_DIR=<that folder> streamlit run eval/label_app.py` on a sample (for example one query per task) and compare with these grades.
Do not overwrite these files with human grades without moving them first.
